## Описание
Программа считает теплопередачу при поперечном обтекании воздухом одиночного цилиндра: тепловой поток Q, число Нуссельта Nu и число Рейнольдса Re по формулам (1), (2) и (3) из задания. Скорость воздушного потока w берется из заданного списка: 1, 2, 5, 10, 20 м/с. Серию обрабатывает цикл for, а формула для Nu выбирается внутри цикла условием. При Re < 5 * 10^4 используется первая ветка (0.197 * Re^0.6), в остальных случаях вторая (0.023 * Re^0.8). Значение Re, равное границе, попадает во вторую ветку. В таблице получается 5 строк.

## Входные данные
Вводятся с клавиатуры по запросам программы, дробные числа через точку, малые значения можно писать в экспоненциальной форме:
- d: диаметр цилиндра, см (в варианте 25);
- l: длина цилиндра, м (в варианте 6);
- nu: вязкость воздушного потока, м^2/с (в варианте 2.2e-5);
- lambda: коэффициент теплопроводности цилиндра, ккал/(м*с*град) (в варианте 8.3e-6);
- dt: температурный перепад, град (в варианте 80).

Список скоростей w задан в программе по условию варианта.

## Выходные данные
Одна общая таблица с заголовком и единицами измерения:
- w (m/s): скорость воздушного потока;
- Q (kcal/s): тепловой поток;
- Nu: число Нуссельта;
- Re: число Рейнольдса.

## Как запустить
Открыть проект в Visual Studio (Console App, C++17), собрать и запустить без отладки: Ctrl+F5. Ввести пять значений по одному на строке.
